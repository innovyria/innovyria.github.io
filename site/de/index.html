Open Source · Autonomer SDLC

Software aus einem autonomen Entwicklungszyklus.

Jedes Innovyria-Projekt wird durchgängig von KI-Agenten unter menschlicher Leitung entwickelt. Die Agenten schreiben den Code, testen ihn, prüfen ihn in unabhängigen Review-Schleifen, versionieren und veröffentlichen ihn. Ein Mensch setzt die Ziele, entscheidet, was erscheint, und verantwortet das Ergebnis.

Wie sie entsteht

Agenten erledigen die Arbeit. Ein Mensch verantwortet das Ergebnis.

Der gesamte Softwareentwicklungszyklus läuft als automatisierte Schleife von KI-Agenten. Menschen bleiben dort, wo Urteilsvermögen und Verantwortung hingehören: bei den Zielen und bei der Entscheidung, was veröffentlicht wird.

  1. Vorgeben Mensch

    Ein Mensch setzt die Ziele: wofür die Software gedacht ist und was sie können muss.

  2. Bauen Agenten

    KI-Agenten implementieren jedes Feature und schreiben die zugehörigen Tests.

  3. Testen Agenten

    Jede Änderung wird getestet, auch in der laufenden Anwendung und nicht nur in Unit-Tests.

  4. Prüfen Agenten

    Unabhängige Review-Runden stellen die Arbeit infrage. Agenten beheben, was gefunden wird, dann läuft die Schleife erneut.

  5. Veröffentlichen Agenten

    Agenten versionieren, paketieren und veröffentlichen das Release, signiert, mit Prüfsummen und Changelog.

  6. Entscheiden Mensch

    Ein Mensch entscheidet, was erscheint, und trägt die Verantwortung dafür.

Alles Open Source

Jedes Projekt ist freie Software. Sie können lesen, bauen, ändern und weitergeben, was die Agenten erstellen.

Eine öffentliche Spur

Jeder Schritt hinterlässt nachprüfbare Belege: Commits, CI-Läufe, Review-Korrekturen und signierte Releases.

Menschliche Verantwortung

Automatisierung verwässert keine Verantwortung. Ein Mensch gibt die Richtung vor, gibt frei, was erscheint, und steht dafür ein.

Markdown Editor

GNOME · GPL-3.0

Ein Markdown-Editor und -Betrachter für GNOME nach dem Vorbild von GNOME Text Editor. Die Vorschau steht neben dem Text, scrollt mit und stellt dar, was technische Dokumente brauchen.

  • Mermaid-Diagramme aller Typen, KaTeX-Formeln und Syntaxhervorhebung
  • Marp-Foliensätze: ein Dokument mit marp: true erscheint in der Vorschau als Folien
  • GitHub- und Hugo-Konventionen: Hinweisboxen, Aufgabenlisten, Fußnoten, Front Matter, Links zwischen Dokumenten
  • Große Dokumente bleiben flüssig: nur der bearbeitete Abschnitt wird neu gerendert
  • Tabs, Suchen und Ersetzen, Gliederung, Rechtschreibprüfung, Drucken und HTML-Export

Installation

Ein signiertes Flatpak-Repository

Die Apps von Innovyria laufen auf der GNOME-Runtime von Flathub und aktualisieren sich mit flatpak update oder GNOME Software. Das Repository wird aus den Releases der Apps erstellt, und jeder Commit ist signiert.

Eine App installieren

Öffnen Sie die .flatpakref in GNOME Software oder führen Sie aus:

flatpak install --user https://innovyria.github.io/flatpak/io.github._24icewolf42.markdown-editor.flatpakref

Das ganze Repository hinzufügen

Neue Innovyria-Apps erscheinen dann von selbst in GNOME Software.

flatpak remote-add --user --if-not-exists innovyria https://innovyria.github.io/flatpak/innovyria.flatpakrepo
