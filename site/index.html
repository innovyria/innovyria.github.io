How it's made

Agents do the work. A person owns the result.

The whole software development lifecycle runs as an automated loop of AI agents. People stay where judgement and accountability belong: at the goals and at the decision to ship.

  1. Direct Human

    A person sets the goals: what the software is for and what it has to do.

  2. Build Agents

    AI agents implement each feature and write the tests that go with it.

  3. Test Agents

    Every change is tested, including in the running application, not only in unit tests.

  4. Critique Agents

    Independent review rounds challenge the work. Agents fix what the reviews find, then the loop runs again.

  5. Release Agents

    Agents version, package and publish the release, signed, with checksums and changelog.

  6. Decide Human

    A person decides what ships and is accountable for it.

Open source, all of it

Every project is free software. You can read, build, change and redistribute what the agents produce.

A public trail

Every step leaves a record you can inspect: commits, CI runs, review fixes and signed releases.

Human accountability

Automation does not dilute responsibility. A person sets the direction, approves what ships and answers for it.

Markdown Editor

GNOME · GPL-3.0

A Markdown editor and viewer for GNOME, modelled on GNOME Text Editor. The preview sits next to the text, scrolls with it and renders what technical documents use.

  • Mermaid diagrams of every type, KaTeX math and syntax highlighting
  • Marp slide decks: a document with marp: true previews as slides
  • GitHub and Hugo conventions: alerts, task lists, footnotes, front matter, links between documents
  • Large documents stay responsive: only the edited section re-renders
  • Tabs, find and replace, outline, spell checking, printing and HTML export

Install

One signed Flatpak repository

Innovyria's apps run on the GNOME runtime from Flathub and update with flatpak update or GNOME Software. The repository is rebuilt from each app's release and every commit is signed.

Install an app

Open the .flatpakref in GNOME Software, or run:

flatpak install --user https://innovyria.github.io/flatpak/io.github._24icewolf42.markdown-editor.flatpakref

Add the whole repository

New Innovyria apps then show up in GNOME Software on their own.

flatpak remote-add --user --if-not-exists innovyria https://innovyria.github.io/flatpak/innovyria.flatpakrepo
